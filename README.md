# Simple Python HTTP Server
This project is a basic local web server built using Python's built-in tools. 
It serves a fun welcome page when you visit the main link and shows an error page for any other link. 
Features Built-in Tools: Runs completely on Python without installing extra libraries.
Custom Welcome Page: Displays a moving marquee text on the homepage.Error Handling: Sends a clear 404 "Page Not Found" message for invalid links.
## Prerequisites 
You only need Python 3 installed on your computer to run this project.
### How to Setup and Run, Follow these easy steps to get your server running:
Save the Code: Copy the Python code and save it in a file named server.py
Open Terminal: Open your command line, terminal, or command prompt.Navigate to Folder: Move into the folder where you saved your file.
Start the Server: Run the following command on Linux:  python3 server.py
## View the Site: 
Open your web browser and go to http://localhost:8000 
Server Routes http://localhost:8000/ - Displays the welcome message.
http://localhost:8000/any-other-page - Returns a 404 Error:Page Not Found message.
